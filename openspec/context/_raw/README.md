# _raw — исходники для интервью

Для этого проекта внешних исходников нет: всё, что описывает продукт, лежит в самом репозитории и является источником правды:

- `README.md` — стенд, контракт сервиса, как запускать, как сдавать;
- `GRADING.md` — как устроена проверка (diff файлов, сборка, сценарии);
- `docs/TASK_1.md` — условие задания 1: сценарии S1–S5, уровни, требования;
- `contracts/*.yaml` — OpenAPI: Orders (ваш), Payment, Inventory;
- `runner/` + `runner/params/task1.json` — код раннера (что именно проверяется) и открытые параметры;
- `mocks/` — код заглушек (как именно имитируются отказы);
- `orders/`, `examples/` — текущая/наивная реализация.

Если появятся материалы вне репозитория (постановки, конспекты, ответы преподавателя) — складывать сюда как .md/.txt.

Папка временная: после заполнения context/ её можно оставить пустой или удалить.
